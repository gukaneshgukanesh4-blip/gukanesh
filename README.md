# GUKANESH C — Student Developer Portfolio

A responsive portfolio built using only HTML, CSS, and vanilla JavaScript. No frameworks, package installation, or build tools are required.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation, reveal animations, and footer year

## Run locally
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `gukaneshgukanesh4-blip.github.io` or any repository you prefer.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
